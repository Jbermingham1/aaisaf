# TA08.009 — Cookie Consent Bypass or Absence

## Overview

| Field | Value |
|-------|-------|
| **ID** | TA08.009 |
| **Tactic** | [Access Control Subversion](../../tactics/TA08-access-control.md) |
| **Severity** | Medium |
| **AISS Score** | 5.5 |
| **System Types** | A, B, C, D, E, F, G |

## Description

AI-serving web portals deploy analytics, tracking, and session recording services without implementing functional cookie consent mechanisms — or with consent mechanisms that are present but non-functional (decorative banners, disabled in source code, no actual script-blocking on rejection).

This creates a compliance gap where personal information is collected from every visitor without informed consent. When combined with AI system interactions (prompts, responses, configuration), the unconsented data collection extends to AI-specific behavioural data.

Common patterns include:
- No consent banner at all (scripts load immediately on page visit)
- Consent banner present but `isCookieBannerEnabled: false` in source code
- Consent banner present but non-essential scripts load regardless of user choice
- Cookie notice that links to privacy policy but provides no opt-in/opt-out mechanism

## Attack Vector

**Prerequisites:**
- Target portal serves AI system interactions
- Analytics or tracking services are embedded
- No functional cookie consent mechanism

**Procedure:**
1. Visit target portal and observe whether a cookie consent banner appears
2. Inspect page source for consent management platform configuration
3. Check browser DevTools → Network tab to verify whether tracking scripts load BEFORE consent is given
4. If consent banner exists, reject non-essential cookies and verify whether tracking scripts are actually blocked
5. Document the gap between consent mechanism (or absence) and actual script behaviour

## Detection

- Automated cookie consent auditing tools (CookieBot scanner, OneTrust assessment)
- Manual inspection of page source for consent configuration flags
- Network tab analysis comparing script loading before/after consent interaction
- Privacy compliance audit against applicable legislation

## Remediation

- **Deploy a functional consent management platform** (OneTrust, CookieBot, or equivalent)
- **Ensure non-essential scripts are blocked by default** until explicit opt-in
- **Categorise all cookies and scripts** as essential vs. non-essential
- **Test consent mechanism functionality** — verify scripts actually stop loading when consent is withheld
- **Document cookie usage** in a publicly accessible cookie policy
- **Conduct regular compliance audits** against Australian Privacy Act, GDPR, and ePrivacy requirements
